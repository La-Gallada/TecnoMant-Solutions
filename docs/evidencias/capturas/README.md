# Estado de evidencias visuales

Esta carpeta se reserva para capturas reales de ejecución con los nombres `E01_Dashboard.png` a `E10_Resultados_JUnit.png` definidos en `../CAPTURAS_MANUALES.md`.

Durante la validación se inspeccionó la aplicación JavaFX real, pero la herramienta de automatización disponible no permite exportar sus capturas a archivos verificables dentro del proyecto. Por esa razón esta entrega no incluye imágenes fabricadas, mockups ni capturas reconstruidas.

Para completar esta carpeta manualmente, ejecute `mvn javafx:run`, siga la guía indicada y capture únicamente la ventana de TecnoMant. Antes de entregar, revise que cada imagen sea legible, no incluya otras ventanas ni datos sensibles y corresponda a una ejecución real.
